Telegram alerts (optional)
Needs internet. Sends one message when status turns UNSAFE (30 s cooldown). The token stays in this browser. Note: if you're joined to the ESP32's own Wi-Fi there is no internet, so alerts only work in demo mode or when the ESP32 is on a network with internet.
Status rule: SAFE when pH is 6.5–8.5 AND TDS out ≤ 500 ppm. Removal % = (TDS_in − TDS_out) / TDS_in × 100.
