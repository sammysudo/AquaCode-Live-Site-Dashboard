# 🌊 SafiSense: Real-Time Water Quality Dashboard

SafiSense is a lightweight, real-time web dashboard designed to monitor water quality. It combines deterministic safety rules (WHO guidelines) with a Machine Learning (SVM) model to provide two simultaneous verdicts: a **Rule Verdict** and an **ML Verdict**. 

This project was built as an educational tool to demonstrate the intersection of hardware sensors, machine learning pipelines, and modern web data visualization.

## ✨ Features

*   **FastAPI Backend:** A lightweight Python server that ingests sensor data, runs real-time ML inference, and serves the frontend.
*   **Machine Learning Integration:** Uses a pre-trained Support Vector Machine (SVM) pipeline (`joblib`) to predict water safety based on pH, TDS, and Temperature.
*   **Vanilla Web Frontend:** No React, no Vue, no Chart.js. The dashboard is built with raw HTML, CSS, and JavaScript, making it 100% offline-capable and incredibly fast.
*   **HTML5 Canvas Charting:** A custom-drawn, auto-scaling real-time line chart that tracks TDS levels.
*   **Three Data Modes:** 
    *   *Simulated:* Generates fake data for offline demos.
    *   *ESP32:* Connects directly to a local hardware sensor via Wi-Fi.
    *   *Server:* Connects to the FastAPI backend to display live data alongside ML predictions.

## 🚀 Local Setup & Installation

**1. Clone the repository:**
```bash
git clone https://github.com/yourusername/safisense.git
cd safisense
```

**2. Install Python dependencies:**
```bash
pip install -r requirements.txt
```
*(If you don't have a `requirements.txt`, run: `pip install fastapi uvicorn[standard] joblib scikit-learn numpy pandas`)*

**3. Start the FastAPI server:**
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

**4. Open the dashboard:**
Navigate to `http://localhost:8000` in your web browser. 

## 🌐 Deployment (Render)

Because FastAPI serves both the backend API and the frontend HTML, you can deploy this entire project as a single web service.

1. Push your code to a GitHub repository.
2. Go to [Render.com](https://render.com) and create a new **Web Service**.
3. Connect your GitHub repository.
4. Use the following settings:
   *   **Environment:** `Python 3`
   *   **Build Command:** `pip install fastapi uvicorn[standard] joblib scikit-learn numpy pandas`
   *   **Start Command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`
   *   **Root Directory:** `SafiSense_server` This is for mapping the directory for the main.py file
5. Click **Deploy**.

## 🧠 The Lesson (Rule vs. ML)

The dashboard deliberately displays two badges (say like labels) side-by-side:
1.  **The Rule Pill (WHO Guidelines):** Safe if pH is 6.5–8.5 and TDS ≤ 500 ppm.
2.  **The ML Badge (SVM Model):** A prediction generated by a model trained on a dataset with *stricter* labels (TDS ≤ 200 ppm).
This comparison is what will be used to determine the final decision on the predicted water quality since the WHO rule includes a much wider range than the ML one since it was a bit more strict

**Why they disagree:** In the 200–500 ppm TDS range, the Rule says **SAFE**, but the ML model says **UNSAFE**. This visually demonstrates a core Machine Learning lesson: *A model is only as smart as the data it was trained on. If the labels are strict, the model will be strict.*

## 🛠️ Testing the API (Without Hardware)

If you don't have an ESP32 connected, you can simulate a water reading using the built-in Swagger UI:
1. Go to `http://localhost:8000/docs`.
2. Open the **`POST /api/readings`** endpoint and click **"Try it out"**.
3. Paste this JSON payload:
   ```json
   {
     "ph": 7.1,
     "tds_in": 400,
     "tds_out": 350,
     "temp_c": 24,
     "turbidity": 1
   }
   ```
4. Click **Execute**. 
5. Go back to your dashboard (`http://localhost:8000`), select **Server (live + ML)**, and click **Start**. You will see the data render instantly.
